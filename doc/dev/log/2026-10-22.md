## Phase 0: dev container

- Docker Engine (docker-ce) installed on the workstation.
- Added `docker/Dockerfile`, `scripts/pbdev` (image tag = hash of `docker/`) and
  `scripts/ci/test.sh`. bpak v0.9.3 builds fine against Debian's Mbed TLS 3.6.
- The first run crashed in `test_part` (`*** Abort` at DFAR 0x841b0001). Investigation:
  - Jonas suspected the gcov hack. It was broken twice over: GCC 14 has 9 counters (F-013), and
    the counter record length has been in bytes since GCC 12 (F-014). Both fixed. Verified with
    gcov-dump, and the counts merge across boots.
  - The crash itself was F-012: the A/B state callbacks ran with a NULL config after a failed GPT
    init. It used to "work" because the older QEMU on the CI runner apparently had harmless contents at that address (not verified).
    Fixed with guards.
- `test_cli`: click >= 8.2 returns 2 for a group without a command. Updated the test and require `click>=8.2`.
- gcovr 8.7 crashes (KeyError in remove_internal_functions); pinned 8.3. `make gcovr` now uses
  `$(CROSS_COMPILE)gcov`.
- Result: 43/43 tests pass, coverage 54% of lines.
