## Fixed F-053, F-054, F-056

- Test teardown now fails on a non-zero pb-host exit or a sanitizer report in the log. Before, the
  reset at teardown hid them. No existing test had a hidden report.
- `pbtest.Wire` (`device.wire()`): raw wire client. `test_stream.py` covers stream buffer id, size and
  offset bounds. 12 of its 13 tests failed before the fix; the end-of-partition one failed because
  `bio_write` returned `-PB_ERR_IO` for range errors while `bio_read` returned `-PB_ERR_PARAM`.
- `stream_check()` in `cm_main.c` bounds buffer id/size/offset. A failed stream read no longer sends
  two results (the second one desynced the host).
- `check_lba_range` uses 64-bit arithmetic (`test_bio.c`).
- GPT headers with more than 128 entries or entries that aren't 128 bytes are rejected, and the entry
  loop is bounded (`test_gpt.c`; ASan reproduced the overflow before the fix).

## Compatibility guards 1 and 2 (branch `compat-guards`)

- Guard 1, frozen layout: `tests/compat/abi_dump.c` prints every wire struct size and field
  offset, the wire enum values, the bpak header layout, kinds, flags and ids, and the internal
  values that go on the wire unchanged (low byte of `BIO_FLAG_*`, `slc_t`). `check_abi.py` checks
  it against `abi.txt` (ctest `compat.abi`) and that `abi.txt` only grows (CI `compat` job against
  the base branch, pre-commit against HEAD). `_Static_assert`s on every struct size in `wire.c`,
  and on bio flags/`slc_t` against the wire values in `cm_main.c`.
- Guard 2, golden images: `tests/compat/bpak/generate.sh` made five images with bpak 0.9.3 (one per
  hash/signature kind, two parts with an unaligned one, a `dont-hash` part). `test_compat.py` boots
  each from RAM and from a partition, checks `SHA256SUMS`, pins `pb_id()` to the bpak ids and checks
  the Python mirrors (`SLC`, `PartitionFlags`, `PB_CMD_*` in `pbtest.py`) against `abi.txt`. CI fails
  if a committed image changes or disappears.
- The `dont-hash` image fails with `-PB_ERR_BAD_PAYLOAD` after the signature verifies, which
  confirms F-076 (strict xfail). F-076's text had the wrong CLI flag (`--set-flag dont-hash`).
- `Device.boot()` now fails as soon as pb-host enters command mode instead of waiting out the exit
  timeout (that took 10 s per failed boot).
- Left: guards 3-5, images from older bpak CLIs, then the compat fixes F-075..F-077.
