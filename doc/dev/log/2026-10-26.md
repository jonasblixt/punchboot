## TZASC on the i.MX6UL (F-096)

- Branch `imx6ul-tzasc` (from master). Replaces jiffy testbench patch 0005, which did the same
  from the jiffy board code (`late_boot_cb`).
- `src/drivers/tzc/tzc380.c`: Arm TZC-380 driver, `tzc380_init()` and
  `tzc380_configure_region()` (region 1 and up, power of two sizes from 32 KiB, base aligned to
  the size, within the address width). `DRIVERS_TZC380` has no prompt, `PLAT_IMX6UL` selects it.
  Unit test `test_tzc380.c` against a register file in RAM.
- `plat_init()` (imx6ul) checks TZASC1_BYP in IOMUXC_GPR9 and opens the MMDC window
  (0x80000000, 2 GiB) to both worlds in region 1. An error is logged, not returned: a failing
  `plat_init()` skips `plat_board_init()`, and command mode then has no CAAM or eMMC to recover
  with.
- The bypass bit stays in the board's DCD (`src/board/jiffy/imximage.cfg`): pb runs from DDR, so
  it can't be set from pb (the bit may only change while no DDR access is in flight).
- Left: check on jiffy (boot through OP-TEE, `devmem 0xbe000000` from Linux faults, the error
  shows with the DCD line removed after a power cycle). The test bench gets the same change as
  patches on v2.7.0.
