  every step. A failed RoT or SLC fails closed as before, and never rested on the missing
  boot driver: the life cycle is unknown, so command mode asks for authentication and

  wrote the state over LBA 0 of the disk. That is F-393, with the agent on `ab_state.c`.

  that appended one no longer do. On the wire a text that fits is what it was.
